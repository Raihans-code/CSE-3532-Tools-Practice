1. What is the difference between var, let, and const?

var is function-scoped and can be redeclared. let and const are block-scoped. let can be reassigned, while const cannot be reassigned after it is created.

2. What is the difference between == and === in JavaScript?

== compares values after converting them to the same type, so 5 == "5" is true. === compares both value and type, so 5 === "5" is false. Using === is safer because it avoids surprising conversions.

3. What does addEventListener do, and why use it instead of onclick?

addEventListener attaches a function that runs when an event such as a click happens. Unlike onclick, you can add several listeners to the same element for the same event, and you can remove them later with removeEventListener.

4. What is the difference between forEach and map?

forEach loops over an array and runs a function on each item, but it returns nothing. map also loops over every item, but it returns a new array made from the results of the function.

5. What are template literals and how do you use them?

Template literals are strings written with backticks that can hold variables and expressions inside ${ }. Example: const name = 'Ada'; console.log(`Hello, ${name}!`);
